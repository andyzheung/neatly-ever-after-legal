# Neatly Ever After legal pages

Static, bilingual support, privacy, and terms pages for the App Store listing. They are intentionally a separate site from everdot because the two apps have different data practices and product features.

Publish this directory as the root of a public GitHub Pages repository named `neatly-ever-after-legal`, then use:

- Support: `https://andyzheung.github.io/neatly-ever-after-legal/`
- Privacy: `https://andyzheung.github.io/neatly-ever-after-legal/privacy.html`

Do not publish until the released build still has no data collection, advertising, analytics, or live in-app purchases. Update the policy first if those facts change.
